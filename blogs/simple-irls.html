Simple iteratively reweighted least-squares fitting

A simple data set that follows a simple linear trend. There is a single outlier (orange) that biases a fitted model (red). Fitting the data using an IRLS approach mitigates the effect of the outlier, and the resulting model (green) follows the "real" data much more closely.

The method of performing a simple iteratively reweighted least-squares fit is as follows:

  1. Begin by performing a simple least-squares fit to all data points, \(y_i\). The result of this initial step corresponds to the red "naive" fit show in the figures on this page. This fit forms the trial model.
  2. Calculate the residuals, \(e_i\), of the trial model:
    3. $$ e_i = y_i - \hat{y}_i, $$
  3. Use the residuals to create weights \(w_i\) for the next iteration of the fit. I favour the weight formula
    4. $$ w_i = \frac{1}{\text{max}(|e_i|, \delta) }. $$ which I find to be sufficiently robust for many applications. This formulation of the weights means that the regression tends to the least absolute error (LAE) or L1 regression. The \(\delta\) term is a small correction which prevents a divide-by-zero error in the rare case where a residual is exactly zero.
A slightly more complex data set consisting of 100 data points, including 20 outliers (orange). A naive least-squares fit to the data set is affected by the outliers, whereas the IRLS fit better captures the shape of the central data — a nice tight parabola!

The full Python code to perform the IRLS fits above is shown below:

import numpy as np

def weighted_fit(predictors, response, weights=None):
  # Simple function to perform a weighted fit
  # Takes a tuple of predictors and a response
  # Returns the fitted parameters

  p = len(predictors) # number of predictors
  n = len(response) # number of observations
  X = np.ones((n, p+1))
  for i in range(p):
    X[:,i+1] = predictors[i]
  if weights is not None:
    W = np.diag(weights)
  else:
    W = np.diag(np.ones(n))
  XtW = X.T @ W
  try:
    beta = np.linalg.inv(XtW @ X) @ XtW @ response
  except np.linalg.LinAlgError as error:
    if 'Singular matrix' in str(error):
      print("Singular matrix detected, returning None")
      pass
    else:
      raise
    return None
  return beta

def irls(predictors, response, input_weights=None, tol=1E-6, delta=1E-6):
  p = len(predictors) # number of predictors
  n = len(response) # number of observations
  if input_weights is None:
    base_weights = np.ones(n)

  # Do an initial fit to find the "naive" betas
  trial_beta = weighted_fit(predictors=predictors, response=response, weights=base_weights)

  # Iterate until the betas stop changing (within the tolerance)
  iterations = 1
  while True:
    # Build the model
    model = np.ones(n)*trial_beta[0] # intercept term
    for i in range(p):
      model += trial_beta[i+1]*predictors[i]
    
    # Calculate the residuals and use these to update the additional weights,
    # replacing anything smaller than delta with delta to avoid /0 errors
    residuals = np.abs(model - response)
    residuals[residuals<delta]=delta
    trial_weights = 1.0 / residuals # Should converge to MAE
    model_weights = base_weights * trial_weights
    reweighted_beta = weighted_fit(predictors=predictors, response=response, weights=model_weights)

    # If the tolerance is reached, finish and return the betas
    # (Fractional change in the betas)
    if ((np.abs(reweighted_beta - trial_beta) / np.abs(trial_beta)) <= tol).all():
      print(f"IRLS converged after {iterations} iterations")
      return reweighted_beta
    # Otherwise update the trial betas and continue
    trial_beta = reweighted_beta
    iterations += 1
